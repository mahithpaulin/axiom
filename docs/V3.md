# Axiom V3 — staged capability + agent upgrade

V2.5 is the base: stratified Datalog + CDCL SAT + theories (RDL/UF) + CSP
(all-different Régin, bounds) + state planning (Dijkstra + BMC) + search
(A*/IDA*/alpha-beta) + chess self-play + go captures + deterministic chooser,
all under `src/repr.rs`. V3 keeps that base green and adds three stages in
dependency order. Every slice is a pushed branch verified by GitHub Actions
(the only compute used). No slice may break `cargo test`, `cargo clippy -D
warnings`, or `cargo fmt --check`.

Dependency policy (DD-0007 update): the `axiom` core crate stays **zero
runtime dependencies**. New crates under `crates/` (`axiom-mcp`,
`axiom-tui`, later `axiom-py`) **may use dependencies but stay Rust-first**:
blocking HTTP (`ureq`), TUI (`ratatui`/`crossterm`), JSON (`serde_json`)
only outside the reasoning path. No dependency may ever change an answer,
only how it is transported or displayed — every verdict still carries its
own proof.

## Stage A — correctness + language (first, blocks everything else)

1. **A8 fix**: `Limits::clamped` already caps arity/depth; add hard errors
   (not silent truncation) when `max_arity > u16::MAX` or `max_depth > 4096`
   is requested, with regression tests.
2. **V2 text language**: `domain`/`constraint`/`state`/`action`/`position`/
   `move` directives in the exterior (`LANGUAGE_SPEC.md` records exactly
   what parses per slice). Rust API stays authoritative until the parser
   catches up.
3. **B8 IR serialisation**: versioned arena + symbol-table dump/reload with
   rehash-on-load; decision recorded on whether proofs survive a round trip.
4. **PERFORMANCE.md**: write the missing file; every measurement cited in
   ROADMAP lands there (I1 counters, DD-0006/DD-0014, v2.5-exp table).
5. **B3 anti-join**: stratified negation by set subtraction instead of
   per-candidate groundness blocking (new rule-evaluation strategy, behind
   the status contract — `Refuted` stays earned).

Done means: text-language corpus green, round-trip tests, perf doc exists,
`cargo test --lib --tests` + doc + clippy + fmt green.

## Stage B — speed + scale

1. **Memory (C2)**: flat arena for the two `Derivation` `Vec`s (one
   allocation per derivation, same fix IR serialisation needs); target
   <150 B/fact with proofs on, `ProofMode::Off` stays honest (`Found`).
2. **Selectivity (C3) + magic sets**: per-body-position selectivity estimate,
   seed most-selective first; magic-sets rewrite as an optional pass.
3. **Parallel search**: Rayon-free (keep zero-dep) — `std::thread` scoped
   portfolio for SAT/CSP/search with deterministic winner + proof
   (no answer changes, only which engine produced it).
4. **Incremental solving**: `Solver::retract`/`assert` deltas over the same
   `Program` for agent loops (no re-grounding per tool call).

Done means: A/B rows via `Bench::compare` on deterministic counters first
(`candidates`, `derivations`), wall time second; scaling table extended.

## Stage C — ecosystem: any agent can call Axiom (MCP + TUI)

`crates/axiom-mcp`: stdio JSON-RPC (MCP `initialize` / `tools/list` /
`tools/call`, line-delimited) exposing, at minimum:

- `axiom_prove { program: string, query_index?: u32, max_steps?: u64 }`
  → `{ status, summary, steps, proof_present }`
- `axiom_sat { dimacs: string, max_steps?: u64 }`
  → `{ status, summary, steps }`
- `axiom_version {}` → `{ name, version, representations }`

`crates/axiom-tui`: Rust TUI (ratatui) with two providers on day one:

- **OpenAI-compatible** (`OPENAI_BASE_URL` / `OPENAI_API_KEY` /
  `OPENAI_MODEL`; covers OpenAI, Ollama, LM-Studio, vLLM, OpenRouter).
- **Anthropic native** (`ANTHROPIC_API_KEY` / `ANTHROPIC_MODEL`,
  Messages API + tools).

Loop: chat → LLM tool-call → local Axiom execution (direct crate call,
not subprocess) → result fed back → final answer. Axiom answers surface
the `Status` honestly (`Exhausted`/`Unknown` never render as negatives).

## Landing plan (rapid slices, Actions-verified)

1. **Slice 1 (this branch)**: this doc + `axiom-mcp` std-only stdio
   server + `axiom-tui` skeleton (providers + `axiom_prove` tool path) +
   workspace + CI jobs. Raw capability first.
2. **Slice 2**: Stage A items (A8, text language slice, serialisation).
3. **Slice 3**: Stage B items, each with A/B bench rows.
4. **Slice 4**: TUI streaming, MCP stdio bridge mode, provider matrix
   tests (mocked HTTP, no keys in CI).

## Deliberately not in V3

- No GPU path, no neural components in the reasoning path (ROADMAP
  non-goals stand; a neural heuristic must beat a symbolic one
  reproducibly before it is considered, and proofs still check it).
- No monetised hosting on free tiers: public-repo Actions only, no
  quota evasion (see repo memory/AGENTS rules).
